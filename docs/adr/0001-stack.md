# ADR-0001. Технологический стек MVP

Статус: принято для MVP · 2026-10

## Контекст

Исходный ориентир: React + TypeScript + React Three Fiber / Three.js, Blender + GLB, Zustand, отдельная JSON-модель
с формальными схемами, модульный репозиторий. Стек не был утверждён; ниже — что принято, что уточнено и почему.

## Решения

| Область | Решение | Почему |
| --- | --- | --- |
| Рендер | **React Three Fiber + drei** поверх Three.js | Декларативная сцена из модели, зрелая экосистема (контролы, линии, HTML-подписи). Babylon.js/PlayCanvas сильнее как игровые движки, но хуже ложатся на «сцена = функция от модели». |
| Сборка и тесты | **Vite + Vitest** | Мгновенный dev-цикл, один конфиг для приложения и тестов ядра. |
| Схемы | **Zod как единственный источник** → TS-типы, валидация в рантайме, JSON Schema (`npm run export:schema`) | Уточнение к «JSON-модель с формальными схемами»: схемы не пишутся трижды и не расходятся. Импорт, редактор и live-события валидируются одним кодом. |
| Состояние | **Zustand** для модели, выбора, линз; **мутабельные часы** для покадрового времени | Покадровые обновления не проходят через React — нет лишних ререндеров при 60 FPS. |
| Симуляция | **Чистый детерминированный движок** вне React/Three | Тестируемость, сравнение «как есть / как будет», переиспользование для фактических событий. |
| Ассеты | **Процедурные архетипы сейчас, слот GLB в каталоге** | MVP не блокируется на моделировании; замена на Blender-модели не меняет модель и логику. |
| Подписи | **DOM (drei `Html`)** вместо 3D-текста | Чёткий кириллический текст без атласов шрифтов, стилизуется CSS, доступен для выделения. |
| Live | **SSE** + валидация `ModelEvent` | Проще WebSocket для однонаправленного потока; легко проксируется. Интерфейс адаптера позволяет добавить WebSocket/Kafka-шлюз. |
| Происхождение событий | `source: demo \| live` **в схеме события** | Требование «художественная визуализация не создаёт ложного впечатления» закреплено в данных, а не только в UI. |

## Отклонено / отложено

- **ECS (bitECS, Miniplex).** Оправдан при тысячах агентов; в MVP десятки объектов — избыточно.
- **WebGPU-рендерер.** Перспективно, но поддержка браузеров и drei ещё неравномерна; WebGL 2 достаточно.
- **Монорепозиторий из пакетов сразу.** Границы модулей выдержаны в `src/`; выделение в workspaces — когда
  у ядра появится второй потребитель.
- **Граф-БД для модели.** JSON в git даёт ревью, историю и CI-валидацию; база — когда модель начнут
  наполнять адаптеры.
